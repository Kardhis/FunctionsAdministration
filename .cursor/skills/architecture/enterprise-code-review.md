# Enterprise Code Review

When reviewing code:

## Architecture

Review:
- separation of concerns
- coupling
- cohesion
- layering
- reusability

---

## Readability

Review:
- naming
- complexity
- duplication
- file size
- function size

---

## Security

Review:
- validation
- sensitive data exposure
- auth/authz correctness
- injection risks

---

## Frontend review

Review:
- responsiveness
- accessibility
- UX states
- loading/error handling

---

## Backend review

Review:
- transactions
- exception handling
- API consistency
- DTO usage
- repository correctness

---

## Testing

Review:
- missing tests
- edge cases
- regression risks

---

## Final verdict

Classify:
- critical issues
- important improvements
- optional improvements
