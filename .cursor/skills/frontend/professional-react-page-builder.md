# Professional React Page Builder

When creating a page:

## Step 1 — Analyze the page

Identify:
- purpose
- primary user actions
- data dependencies
- states
- edge cases
- responsiveness requirements

---

## Step 2 — Define structure

Split into:
- page container
- sections
- reusable components
- forms
- modals
- tables
- cards

Avoid giant monolithic components.

---

## Step 3 — UX states

Every page must define:
- loading state
- empty state
- error state
- success feedback
- disabled states

---

## Step 4 — Responsive behavior

Ensure:
- mobile-first design
- responsive layout
- usable tables
- readable typography
- touch usability

---

## Step 5 — Accessibility

Ensure:
- semantic HTML
- keyboard navigation
- labels
- focus states
- screen reader friendliness

---

## Step 6 — Final polish

Verify:
- visual consistency
- spacing consistency
- responsive quality
- accessibility quality
- maintainability
